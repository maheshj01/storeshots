# Example: Epoch

The phase 0 fixture: a four-screen Play phone set for
[Epoch](../../../epoch), in English and German, from real `adb screencap`
captures. German has no captures of its own, so it falls back to
`captures/en/`.

    node apps/cli/src/main.ts render examples/epoch
